## 1. Инструкции и запись

- [x] 1.1 Формировать самодостаточный AGENTS.md или CLAUDE.md с описанием, стеком, ролями, задачей первого запуска и проверками. Добавить для выбранных скиллов условия применения и сведения для подключения.
- [x] 1.2 Адаптировать предпросмотр и защищённую запись под один Markdown-файл. Сохранить проверки корня, актуальности diff и отсутствия побочных изменений.
- [x] 1.3 Убрать автоматические вызовы установки и генерацию вспомогательных файлов из сценария выдачи. Описывать необходимую настройку непосредственно в инструкции.

## 2. Рабочее пространство

- [x] 2.1 Хранить снимок проекта и чат по пути папки в локальном хранилище. Восстанавливать локальный снимок при открытии папки и обрабатывать прежний YAML и папки сторонних проектов.
- [x] 2.2 Оставить YAML доступным для явного экспорта и импорта с подтверждением. Убрать запись prelude.yaml из сценария сохранения Markdown.

## 3. Интерфейс и проверка

- [x] 3.1 Заменить Build project на «Подготовить инструкции». Добавить окно с полным Markdown, копированием и явным сохранением, включая просмотр конфликта и подтверждение замены.
- [x] 3.2 Проверить чистую папку, npm-проект, существующий файл инструкций, отмену и устаревший diff, восстановление снимка без YAML и импорт из экспорта.
- [x] 3.3 Проверить на тестовом проекте, что агент может начать подготовку по одному файлу инструкций, включая применение Humanizer, когда он выбран.
