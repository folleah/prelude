## Context

`delivery.rs` формирует файлы для выбранного harness. `preview.rs` записывает конфигурацию через защищённый путь подготовки и применения изменений. `App.vue` после записи вызывает установку npm и показывает дальнейшие шаги. `workspace.rs` уже хранит локальные снимки, а `project.rs` ищет YAML в папке проекта.

## Goals / Non-Goals

**Goals**

- Дать пользователю один готовый документ с деталями проекта и понятной первой задачей для агента.
- Показать Markdown до записи и сохранить его только по явному действию.
- Восстанавливать состояние конструктора и чата на том же компьютере по пути проекта.

**Non-Goals**

- Запуск CLI-агента, произвольных команд или установки из Prelude.
- Генерация исходников приложения, автоматическое развёртывание и разработка профилей для отдельных платформ.

## Decisions

- Сохранить проверку плана и использовать один результат генерации для предпросмотра, копирования и записи. Диалог показывает имя файла и папку проекта, текст отображается как Markdown-источник.
- Собирать текст из описания, выбранных компонентов, ролей, инструкций плана и метаданных каталога. Первый запуск оформляется отдельной секцией. Для скиллов указываются условия применения, локальный путь при наличии и проверенный источник или известная ревизия. Недостающие сведения обозначаются явно.
- Сохранять только основной файл. Подключение остальных файлов и скиллов описывается в инструкции как работа агента. После записи не запускаются менеджеры пакетов.
- Переиспользовать ограничение записи корнем проекта и проверку актуальности предпросмотра. При конфликте пользователь подтверждает замену, увидев diff. Исходный файл сохраняется при отмене или ошибке записи.
- Сохранять снимки в локальном хранилище Prelude по идентичности папки. При открытии приоритет получает локальный снимок, затем доступный прежний YAML, затем анализ проекта. Экспорт и импорт остаются явными действиями.

## Risks / Trade-offs

- Внешние скиллы могут требовать сети или действий в CLI. Инструкции указывают источник и применимость, а агент сообщает о недоступных шагах.
- Снимок и переписка доступны на другом устройстве после явного экспорта и импорта.
- При расхождении плана и манифестов существующего проекта агенту следует сохранить действующий стек и сообщить о расхождении перед его изменением.
