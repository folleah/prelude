## Purpose

Получение проверенной конфигурации в виде локальных файлов существующего или нового проекта.

## ADDED Requirements

### Requirement: Генерация файлов
Приложение SHALL строить файлы для формата выбранного harness из проверенного плана, включая AGENTS.md и SKILL.md там, где применимы, а также конфигурации агентов и компонентов. Секреты SHALL исключаться из содержимого выдачи.

#### Scenario: Разные harness
- **WHEN** один план представлен в поддерживаемых форматах двух harness
- **THEN** каждый набор использует поддерживаемые этим harness имена, пути и структуру

### Requirement: Предпросмотр и запись
Приложение SHALL показывать список добавлений и изменений и diff существующих текстовых файлов перед подтверждением. Применение SHALL ограничиваться корнем проекта, проверять актуальность предпросмотра и восстанавливать исходное состояние при частичном сбое или показывать данные для восстановления.

#### Scenario: Изменение после предпросмотра
- **WHEN** целевой файл изменился перед применением
- **THEN** запись блокируется до нового предпросмотра

#### Scenario: Выход за пределы корня
- **WHEN** целевой путь выходит из каталога через навигацию или ссылку
- **THEN** запись отклоняется

#### Scenario: Подтверждённое применение
- **WHEN** план корректен и подтверждённый предпросмотр актуален
- **THEN** меняются только указанные в предпросмотре файлы

### Requirement: Создание проекта в пустой папке
Приложение SHALL создавать показанные в подтверждённом предпросмотре файлы в выбранной существующей пустой папке с сохранением структуры каталогов.

#### Scenario: Создание проекта из идеи
- **WHEN** пользователь выбирает заранее созданную пустую папку и подтверждает актуальный предпросмотр
- **THEN** приложение создаёт в папке файлы из предпросмотра

#### Scenario: Папка занята или отсутствует
- **WHEN** выбранная папка отсутствует или содержит хотя бы один файл или вложенную папку
- **THEN** создание проекта отклоняется
