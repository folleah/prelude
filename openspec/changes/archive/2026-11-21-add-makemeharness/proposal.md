## Why

Ручная сборка окружения агентной разработки требует сопоставлять форматы harness, возможности моделей, стоимость и правила проекта. MakeMeHarness собирает редактируемую конфигурацию и объясняет, какие компоненты нужны проекту.

## What Changes

- Создать бесплатное open-source приложение MakeMeHarness для Windows, macOS и Linux на Tauri, Rust, Vue 3, TypeScript и Tailwind CSS.
- Принимать описание идеи или локальный репозиторий, список доступных провайдеров, бюджет и приоритет экономии или качества.
- Получать от ИИ план окружения с harness, моделями, ролями и модулями из расширяемого локального YAML/JSON-каталога.
- Формировать, объяснять и проверять редактируемую конфигурацию. Генерировать файлы и применять их после предпросмотра либо создавать настроенный проект в заранее созданной пустой папке.
- В первой версии получать план автоматически через Sign in with ChatGPT с разрешением на использование подписки либо через API выбранного ИИ-провайдера с пользовательским ключом и предоставлять модели доступ к локальному каталогу через MCP.

## Capabilities

### New Capabilities

- `environment-planning` — ввод, реестр, рекомендации, объяснения, редактирование и проверка.
- `configuration-delivery` — генерация, предпросмотр, локальное применение и создание проекта.

## Impact

Репозиторий содержит структуру OpenSpec. Потребуются новый desktop-проект, каталог, адаптеры форматов harness и опциональные клиенты облачных LLM. Граница продукта — проектирование и сборка окружения для существующих инструментов. Запуск агентов и оркестрация находятся за этой границей.

В запросе использованы два имени. В артефактах принято MakeMeHarness по названию проекта и репозитория.
