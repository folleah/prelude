## Why

Пользователю нужен генератор инструкций для агента. Сейчас даже черновик привязан к папке, а выдача Markdown устроена как запись в проект.

## What Changes

- Оставить на стартовом экране «Новый проект», «Анализ существующего проекта» и локальную историю черновиков History. Убрать постоянную привязку конструктора к папке.
- Открывать новый проект в пустом конструкторе с модальным окном первого промпта. Клик за пределами окна закрывает его.
- Использовать выбранную папку существующего проекта для чтения правил, определения стека и обнаружения скиллов. Заполнять канвас найденными элементами.
- При правках через чат учитывать исходные инструкции и сохранять правила, которых запрос не касается.
- В «Подготовить инструкции» показывать итоговый Markdown и кнопку «Скачать». Использовать `AGENTS.md` для Codex и OpenCode и `CLAUDE.md` для Claude Code.

### Modified Capabilities

- `local-project-workspace` — стартовый экран, модальный ввод и анализ существующего проекта.
- `configuration-delivery` — ревизия исходных инструкций и выдача Markdown через скачивание.

## Impact

Меняются навигация Vue, локальный анализ файлов, входные данные планировщика и сценарий выдачи Markdown.
