## Context

Сейчас `App.vue` хранит путь назначения, восстанавливает проекты через локальные снимки и вызывает команды предпросмотра и записи. `project.rs` умеет находить часть локальных скиллов и признаков стека, но прежний prelude.yaml завершает ветку анализа раньше чтения правил проекта. Генератор уже собирает один Markdown из плана.

## Goals / Non-Goals

**Goals**

- Два входа в один конструктор и единая выдача скачиваемого Markdown.
- Использование имеющихся правил и компонентов при анализе репозитория и при дальнейших правках через чат.

**Non-Goals**

- Автоматическое применение результата, установка инструментов и запуск команд в анализируемой папке.
- Генерация отдельных файлов правил для всех обнаруженных экосистем.

## Decisions

- У нового черновика есть только описание. Закрытие первого модального окна оставляет доступным чат. Клик по содержимому модального окна не закрывает его.
- Анализ читает папку без требования возможности записи. Для первой версии распознавать AGENTS.md, CLAUDE.md, SKILLS.md, локальные SKILL.md, правила Cursor в .cursor/rules и инструкции GitHub Copilot в .github/copilot-instructions.md. Сохранять относительный путь и область действия каждого источника. Прежний prelude.yaml может дать сведения о схеме, а обнаружение текущих правил и скиллов выполняется и при его наличии.
- На канвасе отличать найденные компоненты от предложенных. Сохранять снимок черновика с чатом, данными анализа и актуальным Markdown локально по ID. История открывает снимок без повторного доступа к папке. Путь в заголовке и привязанные к путям снимки убираются из рабочего сценария. Ранее сохранённые данные на диске не требуется удалять.
- При правке использовать исходный документ соответствующего агента как основу. Дополнительные правила и метаданные скиллов служат контекстом с сохранением области действия. Сохранять положения, которых правка не касается, и явно сообщать о неразрешимых противоречиях.
- Считывать только поддерживаемые файлы в пределах выбранного корня. Содержимое инструкций передавать модели как данные проекта. Исключать файлы секретов и учётные данные. Начало нового черновика сбрасывает контекст предыдущего анализа.
- Предпросмотр и скачивание используют один и тот же сформированный текст. Диалог показывает тело Markdown и кнопку «Скачать». Явный экспорт и импорт YAML остаются отдельными действиями.

## Risks / Trade-offs

- Форматы агентских правил отличаются по области применения. Локальное правило из вложенной папки сохраняет свою область при формировании общего документа.
- Повторный анализ видит состояние папки на момент выбора. Изменения на диске после анализа попадут в результат после нового анализа.
