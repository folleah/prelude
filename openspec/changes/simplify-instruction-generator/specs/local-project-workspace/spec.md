## MODIFIED Requirements

### Requirement: Рабочая навигация
После подключения Prelude SHALL показывать стартовый экран с действиями «Новый проект», «Анализ существующего проекта» и боковой панелью History. Рабочие экраны SHALL предоставлять настройки, выход и возврат на стартовый экран.

#### Scenario: Список проектов
- **WHEN** пользователь открывает стартовый экран
- **THEN** доступны два сценария генерации инструкций и локальная история черновиков

### Requirement: Очистка списка недавних проектов
Prelude SHALL позволять удалить локальный черновик из History кнопкой с иконкой удаления.

#### Scenario: Удаление записи
- **WHEN** пользователь нажимает иконку удаления
- **THEN** локальный черновик исчезает из History без изменения файлов проекта

### Requirement: Открытие стороннего проекта
По действию «Анализ существующего проекта» Prelude SHALL предложить выбрать папку и проанализировать её в режиме чтения. Анализ SHALL обнаруживать правила проекта, локальные скиллы, поддерживаемые конфигурации и признаки стека. Найденные компоненты SHALL отображаться в конструкторе как существующие. Выбранная папка SHALL использоваться только как источник анализа.

#### Scenario: Репозиторий без схемы
- **WHEN** пользователь выбирает проект с правилами или скиллами без prelude.yaml
- **THEN** Prelude заполняет канвас обнаруженными компонентами и сохраняет контекст исходных правил для текущего сеанса

#### Scenario: Повторное открытие проекта на том же компьютере
- **WHEN** пользователь повторно выбирает папку для анализа
- **THEN** Prelude анализирует текущее состояние папки без загрузки привязанного к пути локального снимка

### Requirement: Формат и импорт проекта Prelude
Prelude SHALL поддерживать явный экспорт и импорт версионированного prelude.yaml для переноса схемы. Экспорт SHALL включать описание, схему, допущения и состояние чата при наличии, исключая ключи, токены и секцию settings. При чтении прежняя секция settings SHALL игнорироваться. Экспорт и импорт SHALL работать без постоянной привязки к папке проекта.

#### Scenario: Импорт поверх настроенного проекта
- **WHEN** пользователь импортирует YAML при непустой схеме
- **THEN** Prelude запрашивает подтверждение замены и сохраняет текущую схему при отмене

#### Scenario: Перенос схемы
- **WHEN** пользователь экспортирует YAML и импортирует его в другом экземпляре Prelude
- **THEN** схема и включённое в экспорт состояние восстанавливаются

## ADDED Requirements

### Requirement: Локальная история черновиков
Prelude SHALL автоматически сохранять содержательные черновики в локальном хранилище по идентификатору. Снимок SHALL содержать канвас, чат, актуальные сгенерированные инструкции при наличии и данные анализа без пути к корню проекта.

#### Scenario: Восстановление черновика
- **WHEN** пользователь перезапускает Prelude и выбирает черновик в History
- **THEN** Prelude восстанавливает канвас и чат, а подготовленный Markdown доступен для повторного просмотра и скачивания

### Requirement: Новый проект через модальное окно
Действие «Новый проект» SHALL открывать пустой конструктор с модальным окном для первого промпта. В модальном окне SHALL быть только ввод описания проекта. Клик по области вокруг окна SHALL закрывать его без отправки, оставляя конструктор доступным.

#### Scenario: Отправка первого промпта
- **WHEN** пользователь вводит описание и отправляет его из модального окна
- **THEN** окно закрывается, а обработка описания продолжается в чате конструктора

#### Scenario: Закрытие по клику вне окна
- **WHEN** пользователь нажимает на фон вокруг модального окна
- **THEN** окно закрывается, запрос к модели не отправляется и пользователь остаётся в конструкторе

## REMOVED Requirements

### Requirement: Новый проект и проверка папки
**Reason**: Новый черновик больше не требует выбора и проверки директории.
**Migration**: Используйте модальное окно первого промпта на канвасе.

### Requirement: Отображение пути проекта
**Reason**: Конструктор не привязан к папке проекта.
**Migration**: Выбирайте папку только для одноразового анализа существующих файлов.
