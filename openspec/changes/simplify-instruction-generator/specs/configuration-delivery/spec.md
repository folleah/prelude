## MODIFIED Requirements

### Requirement: Генерация файлов
Prelude SHALL готовить один самодостаточный Markdown-файл по проверенному плану. Имя SHALL быть AGENTS.md для Codex и OpenCode и CLAUDE.md для Claude Code. Текст SHALL включать описание, выбранные инструменты, роли при наличии, настройку, зависимости и проверяемые критерии готовности. Для каждого выбранного скилла SHALL указываться, когда его применять и как найти локальную копию или источник подключения. Учётные данные SHALL исключаться. При анализе существующего проекта генерация SHALL учитывать действующий документ и изменять его по запросу, сохраняя правила, которых запрос не касается. Контекст из дополнительных файлов SHALL учитываться с их областью действия.

#### Scenario: Запуск агента после сборки
- **WHEN** пользователь передаёт скачанный AGENTS.md в Codex и просит подготовить окружение
- **THEN** инструкции позволяют начать работу без чтения prelude.yaml

#### Scenario: Разные harness
- **WHEN** пользователь готовит инструкции для Codex, Claude Code или OpenCode
- **THEN** Prelude выбирает имя файла, которое использует соответствующий агент

#### Scenario: Правило применения Humanizer
- **WHEN** Humanizer выбран для сайта с публичными текстами
- **THEN** документ указывает, когда применять скилл и как получить его инструкции

#### Scenario: Ревизия существующих инструкций
- **WHEN** в исходном AGENTS.md заданы команды тестирования и пользователь просит добавить браузерную проверку
- **THEN** итоговый файл сохраняет исходные правила и включает запрошенную проверку

### Requirement: Доступность действия Build project
Действие «Подготовить инструкции» SHALL отображаться на непустом канвасе и после проверки плана открывать результат без требования выбрать директорию.

#### Scenario: Пустая схема
- **WHEN** канвас не содержит элементов
- **THEN** действие подготовки инструкций скрыто

### Requirement: Действия после сборки
Окно результата SHALL показывать полный текст и имя итогового Markdown и предоставлять действие «Скачать». Клик по фону вокруг окна SHALL его закрывать. Действие скачивания SHALL передавать показанный текст как один Markdown-файл и не изменять файлы анализируемого проекта.

#### Scenario: Сборка для Claude Code
- **WHEN** пользователь готовит инструкции для Claude Code
- **THEN** окно показывает полный текст CLAUDE.md и позволяет скачать его

#### Scenario: Скачивание результата анализа
- **WHEN** пользователь скачивает обновлённый AGENTS.md
- **THEN** скачанный файл совпадает с предпросмотром, а исходные файлы проекта не изменяются

## REMOVED Requirements

### Requirement: Предпросмотр и запись
**Reason**: Prelude выдаёт Markdown через скачивание и не заменяет файлы в открытой папке.
**Migration**: Скачайте результат из окна «Подготовить инструкции».

### Requirement: Создание проекта в пустой папке
**Reason**: Для нового черновика папка не нужна.
**Migration**: Сформируйте инструкции в пустом конструкторе и скачайте Markdown.
