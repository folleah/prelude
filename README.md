# Prelude

Prelude подбирает конфигурацию среды агентной разработки по описанию проекта или признакам локального репозитория. План можно изменить, проверить и использовать для создания файлов в заранее подготовленной пустой папке.

## Локальный запуск

Установите Node.js, Rust и системные зависимости для вашей ОС. [Требования Tauri 2](https://v2.tauri.app/start/prerequisites/)

```sh
npm ci
npm run tauri dev
```

Для production-сборки запустите `npm run tauri build` на целевой ОС. В Windows сборка выдаёт `src-tauri/target/release/prelude.exe`. Запустите EXE напрямую. На машине должен быть установлен Microsoft Edge WebView2 Runtime. На macOS и Linux пакеты появятся в `src-tauri/target/release/bundle`. [Требования Tauri](https://v2.tauri.app/start/prerequisites/) · [Упаковка Tauri](https://v2.tauri.app/distribute/)

## Подключение ИИ

- **ChatGPT.** Нажмите **Continue with ChatGPT**, подтвердите использование подписки в браузере, вернитесь в приложение и укажите модель. Кнопка **Проверить подключение** проверяет доступ к модели и вызов каталога. [Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
- **API-провайдер.** Выберите OpenRouter или укажите HTTPS-адрес совместимого API Chat Completions. Введите идентификатор модели с поддержкой вызова инструментов и ключ. Нажмите **Подключить и проверить**. Ключ хранится в памяти сеанса.

Выберите активное подключение, заполните профиль и подтвердите передачу контекста. Для создания проекта укажите путь к уже существующей пустой папке, откройте предпросмотр и нажмите **Создать проект**.

В Windows Prelude восстанавливает сеанс ChatGPT при запуске под тем же пользователем. После обновления со старой версии войдите ещё раз, чтобы сохранить сеанс. Кнопка **Отключить аккаунт** удаляет сохранённый сеанс с этого устройства.

Для работы без сети нажмите **Сохранить план на этом устройстве**, пока план открыт и прошёл проверку. При следующем запуске нажмите **Открыть сохранённый план без сети**. Если план использует пользовательский каталог, сначала укажите пути к его файлам. Хранится один план, и его можно удалить из приложения. Учётные данные в него не входят.

Для существующего репозитория выберите **Применить к существующему репозиторию**, укажите путь и разрешите конфликты в предпросмотре. Если приложение прервалось во время записи, сохраните папку `.makemeharness-recovery` из корня репозитория. В `manifest.json` указаны затронутые пути, SHA-256 исходных и сгенерированных файлов и имена резервных копий. Сверьте хеши текущих файлов перед ручным восстановлением, чтобы сохранить правки, сделанные после прерывания. Переместите журнал из репозитория после восстановления и создайте новый предпросмотр.

## Расширения каталога

Добавьте путь к локальному файлу YAML или JSON в форме профиля. Файл может содержать одну запись или список записей. Используйте уникальный `id` и `schemaVersion: 1`. Примеры полей и категорий есть во встроенном каталоге. [catalog.yaml](src-tauri/src/catalog.yaml)

Запись `kind: mcp` с `delivery.type: remote_mcp` может задать публичный HTTPS-адрес в `delivery.url`. Для `kind: skill` вариант `delivery.type: skill` принимает `description` и `instructions`. Поле `setupDocs` указывает на инструкции по ручному подключению. Токенные тарифы модели указываются в `model.rate`, отдельно за входной и выходной токен. Источник и дата проверки хранятся в `source` и `checkedOn`.
