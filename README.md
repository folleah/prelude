# Prelude

Prelude — настольное приложение для подготовки инструкций и конфигурации агентов разработки. Опишите новый проект или выберите существующий репозиторий. Prelude уточнит требования в чате, предложит набор инструментов, скиллов и проверок, а затем соберёт ZIP для выбранного агента.

## Быстрый старт

1. Подключите ИИ на экране входа.
2. Выберите **Новый проект** и введите описание либо нажмите **Анализ существующего проекта** и укажите папку репозитория. При анализе Prelude учитывает обнаруженные настройки, инструкции агента и локальные скиллы.
3. Ответьте на уточняющие вопросы по одному или нажмите **Выбери сам**. Готовый план и запланированные хуки появятся в конструкторе. Чтобы изменить план, опишите правки в чате.
4. Нажмите **Экспорт**, выберите агента, проверьте дерево файлов и при необходимости отредактируйте текст в предпросмотре. Повторное нажатие **Экспорт** откроет системный диалог сохранения ZIP.

История хранит планы и переписку локально. Сохранённый конструктор можно открыть из боковой панели **История** на экране проектов. Для переноса плана между устройствами используйте **Сохранить prelude.yaml** и **Импортировать prelude.yaml**. Кнопка **Обновить структуру** повторно генерирует план по исходному описанию и сохранённым ответам на уточнения.

## Подключение ИИ

| Способ | Как подключить |
| --- | --- |
| **ChatGPT** | Выберите ChatGPT и подтвердите доступ к подписке в браузере. Модель выбирается в чате конструктора. |
| **API** | Укажите HTTPS-адрес совместимого API Chat Completions и API-ключ. Можно выбрать готовый адрес, например OpenRouter, или ввести свой. ID модели можно указать при подключении. Для планирования модель должна поддерживать вызов инструментов. |
| **GitHub Copilot**, **Gemini**, **Kiro** | Установите официальный CLI (`copilot`, `gemini` или `kiro-cli`) и убедитесь, что он доступен в `PATH`. Выберите провайдера, нажмите **Открыть вход**, завершите вход и нажмите **Проверить подключение**. Prelude общается с CLI через ACP и использует его модель по умолчанию. |

В Windows Prelude сохраняет сеанс ChatGPT и ключ прямого API в защищённом хранилище пользователя. При подключении через ACP учётными данными управляет CLI провайдера.

[GitHub Copilot ACP](https://docs.github.com/en/copilot/reference/copilot-cli-reference/acp-server) · [Gemini CLI ACP](https://geminicli.com/docs/cli/acp-mode/) · [Kiro CLI ACP](https://kiro.dev/docs/cli/acp/)

## Что попадает в ZIP

| Агент | Основные инструкции | Папки скиллов |
| --- | --- | --- |
| OpenAI Codex | `AGENTS.md` | `.agents/skills/<имя>/SKILL.md` |
| Claude Code | `CLAUDE.md` | `.claude/skills/<имя>/SKILL.md` |
| OpenCode | `AGENTS.md` | `.opencode/skills/<имя>/SKILL.md` |

В дерево попадают файлы, которые Prelude смог подготовить для выбранной цели. Для внешних скиллов Prelude загружает исходный `SKILL.md` и поддерживаемые текстовые файлы из репозитория. Несовместимые модули и ошибки загрузки отражаются в окне экспорта.

Если в плане две роли или больше, Prelude создаёт по файлу на роль в каталоге агентов выбранной цели. Общие инструкции указывают, какие задачи кому делегировать. Если роль одна, её инструкции остаются в основном файле проекта.

Для Codex Prelude может включить проектный хук `Stop` с запланированными тестами, линтингом и проверкой типов. Для этого в плане должен быть npm, pnpm, Yarn или Bun. После распаковки запустите Codex из корня проекта и подтвердите хук через `/hooks`.

Распакуйте архив в проект и откройте его в выбранном агенте. Установку зависимостей и подготовку окружения выполняет агент по экспортированным инструкциям.

## Зависимости проекта

Слой **Зависимости проекта** показывает ключевые пакеты приложения и задачи, которые они закрывают. При анализе репозитория Prelude читает прямые зависимости из корневых `package.json` и `composer.json`. ИИ учитывает их при планировании. Совпадения с манифестом отмечаются на карточках, а выбранные зависимости включаются в инструкции агента.

## Приоритеты скиллов и инструментов

Откройте **Настройки → Приоритеты скиллов и инструментов** и отредактируйте JSON. Ключи в `priorities` — ID модулей из [каталога](src-tauri/src/catalog.yaml). Поле `planning` подсказывает модели, когда выбирать модуль, а `instructions` задаёт условия применения выбранного скилла в инструкциях агента. [Настройки по умолчанию](src-tauri/src/module-preferences.json)

## Разработка и portable-сборка

Установите Node.js с npm, Rust и системные зависимости Tauri для вашей ОС. [Требования Tauri 2](https://v2.tauri.app/start/prerequisites/)

```sh
npm ci
npm run tauri dev
```

Чтобы собрать portable-версию для Windows, запустите на Windows:

```sh
npm run tauri build -- --no-bundle
```

Исполняемый файл появится по пути `src-tauri/target/release/prelude.exe`. Запустите его напрямую. На компьютере должен быть установлен Microsoft Edge WebView2 Runtime. [Справочник CLI Tauri](https://v2.tauri.app/reference/cli/) · [Требования Windows](https://v2.tauri.app/start/prerequisites/#windows)
